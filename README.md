# MLPC - Machine Learning Pattern Classification Project UE 2026

The goal is to develop a Sound Event Detection model for smart home environments. Trained and tested on data which was collected and annotated by all course participants.

---

## Folder Structure
- "data/" - place the dataset here
- "notebooks/" - exploratory analysis and experiments
- "src/" - main scripts or functions
- "requirements.txt" - requirements file for conda env
- "README.md"

# Setup
- git clone <repo_url>
- Get dataset from the courses Moodle page and place it locally in a directory "data"
- create conda env and pip install -r requirements.txt
